# Shopify Theme Check Fix: a free agent skill for Claude Code and Cursor

Runs Shopify Theme Check on your theme, auto-fixes the safe offenses, and flags the risky ones for you to decide.

## Install
Copy `shopify-theme-check-fix/` into `~/.claude/skills/` (Claude Code) or your project's Cursor skills folder, then ask: "clean up Theme Check on this theme".

Requires the Shopify CLI (`npm install -g @shopify/cli`).
